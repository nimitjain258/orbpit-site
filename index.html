ORBPIT

A 24/7 live battle royale on YouTube, where the chat picks the fighters.

How it works

Round orb warriors fight it out in a pixel-art arena, around the clock. Every fight is simulated live, and the top three finish on the podium.

  • Type !join in the live chat to send your own orb into a fight.
  • Type ! followed by a class name to pick how it fights.
  • Type !predict to call the winner and climb the predictor leaderboard.

About the GameSim app

GameSim is the software that runs the ORBPIT stream. It signs in to the ORBPIT YouTube channel only, to find the channel's own live broadcast, read its live chat, and start the broadcast after the stream restarts. It is not offered to anyone else, and it never accesses other people's accounts.
